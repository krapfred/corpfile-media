# corpfile-media

유튜브 쇼츠 채널 **기업해부학** 의 인스타그램 릴스 호스팅 저장소입니다.

## 왜 공개인가

인스타그램 콘텐츠 게시 API 는 영상을 `video_url` 로 받아 **메타 서버가 직접 내려받습니다.**
따라서 인증 없이 접근 가능한 URL 이 필요합니다.

로컬 파일 직접 업로드(`upload_type=resumable`) 경로도 있으나
단일 요청 약 10MB 제한이 있어 본편(20~25MB)에는 쓸 수 없습니다.

## 무엇이 들어 있나

각 화의 완성본 mp4 가 **릴리스 자산**으로만 올라갑니다.
코드도, 자격증명도 없습니다. 여기 있는 영상은 모두 유튜브와 인스타그램에
공개되는 것과 동일한 파일입니다.
